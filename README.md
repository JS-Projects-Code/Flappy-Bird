# 🐦 Flappy Bird — Web Edition

A classic arcade Flappy Bird game built from scratch using **HTML, CSS, and JavaScript**. Dodge the pipes, beat your high score, and play directly in your browser with zero downloads required!

🔗 **[Play the Live Game Here!](https://js-projects-code.github.io/Flappy-Bird/)**

---

## ✨ Features
* **Smooth Animations:** Custom wing-flapping animations and dynamic game-over effects.
* **High Score System:** Automatically tracks your best score during your session.
* **Responsive Controls:** Play effortlessly using your keyboard (`Spacebar` / `Up Arrow`) or mouse clicks / screen taps.
* **Lightweight & Fast:** Built with pure vanilla JavaScript—no external game engines or heavy libraries required.

## 🎮 How to Play
1. Open the **[Live Demo Link](https://js-prrojects-code.github.io/Flappy-Bird/)**.
2. Press **Spacebar**, **Click**, or **Tap** the screen to flap and stay airborne.
3. Navigate through the gaps between the pipes without crashing.
4. Try to beat your high score!

## 🛠️ Built With
* **HTML5** – Game structure and layout
* **CSS3** – Styling, backgrounds, and visual animations
* **JavaScript (ES6)** – Game loop, collision detection, and score logic

## 🚀 Run Locally
If you want to download and modify the code on your own computer:
1. Clone this repository:
   ```bash
   git clone https://github.com[your-username]/[your-repo-name].git
   ```
2. Open the project folder and double-click `index.html` to launch it in any web browser.
